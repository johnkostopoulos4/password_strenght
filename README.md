# Password Strength Checker

A C program designed to evaluate the security level of a password based on specific rules (length, digits, special characters).

## Features
- Checks password length
- Validates complexity
- Simple terminal-based interface

## How to Compile and Run
1. Open your terminal in the project folder.
2. Compile with GCC:
   `gcc password_checker.c -o password_checker`
3. Run the program:
   `./password_checker`
